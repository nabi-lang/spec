# Nabi

[![Content](https://github.com/nabi-lang/spec/actions/workflows/content.yml/badge.svg)](https://github.com/nabi-lang/spec/actions/workflows/content.yml) [![License: CC BY 4.0](https://img.shields.io/badge/license-CC%20BY%204.0-blue)](LICENSE)

The formal specification for the **Nabi** programming language.

Designed and maintained by [Han Damin](https://github.com/miniex) (`@miniex`).

## Editions

- [English](en/README.md) - default
- [한국어](ko/README.md) - Korean

Both editions have the same files and the same section numbers. If they disagree, the English text is the reference.

## Status

Active draft, describing Nabi 0.1. The implementation lives in a separate repository.
