## 本章的作用

本章不直接定义具体的 trait 或类型，而是汇集库**作为整体**必须一致遵循的规则和策略。

**三层级模型**规定依赖的方向：`std` 可以使用 `core` 和 `bare`，`core` 可以使用 `bare`，但不允许反方向的依赖。**导入策略**规定每个用户文件都隐式导入的 prelude `core::prelude`，并列出其中的名称。接下来的**内建函数**一节说明标准库方法如何与编译器后端（PrimOp 等）相连，最后的 **lang 槽**一节说明编译器通过 `#[lang(...)]` 属性查找的 100 个槽如何映射到标准库的项。

只有先定义了这些策略，[200-core/](../200-core/) 中的 trait 定义才能随之展开。
