# 1.9. 布尔字面量与哨兵字面量

Nabi 有三个采用关键字形式、实际上表示值的字面量。在语法上它们定义如下。

```
sentinel_lit    ::= "true" | "false" | "none"
```

## 1.9.1. 布尔字面量

布尔字面量写法如下。

```nabi
true
false
```

布尔字面量恰好由 `true` 和 `false` 两个词法单元组成。这两个名称都在[关键字](105-keywords.md)的保留列表中，不能再用作标识符。它们求值为标准库的布尔类型（`bool`）；其确切定义见类型系统部分。

## 1.9.2. 哨兵字面量：`none`

哨兵字面量写法如下。

```nabi
none
```

`none` 是表示值不存在的唯一字面量。它占据其他语言中 `null`、`nil`、`None` 和 `undefined` 的位置，并作为关键字保留，所以不能用作标识符。它填充哪个和类型的空槽由上下文决定；其语义在类型系统规范中定义。

## 1.9.3. 词法分类

这三个字面量属于[词法结构](102-lexical-structure.md)中的布尔 / 哨兵字面量类别。它们之所以与关键字词法单元种类分开归类，是因为它们是出现在值位置上的词法单元，解析器在可以出现字面量的地方接受它们。

在词法阶段只保证以下一点：`true`、`false` 和 `none` 总是被区分为同一种词法单元，绝不会被重新解释为标识符或其他关键字。

## 1.9.4. 未采用的字面量

其他语言中常见的以下字面量在词法阶段不作为单独的词法单元引入。浮点数的无穷大和 NaN 作为标准库常量提供，而其他形式的“空”，即 `undefined`、`null` 和 `nil`，全部统一为 `none`。**unit** 值（`()`）不在词法阶段出现，而是在表达式阶段以空元组的写法出现。

字面量种类越少，学习成本越低，工具需要支持的范围也越小。
