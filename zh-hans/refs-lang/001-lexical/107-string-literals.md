# 1.7. 字符串字面量

字符串字面量是表示字符序列的词法单元。本文档只涵盖词法形式；结果求值为哪个库类型，由标准库的字面量处理器决定。字节串（1.7.5）是例外：其类型由语言确定。

## 1.7.1. 普通字符串

```
string_lit  ::= '"' string_item* '"'
string_item ::= string_char | escape_seq
string_char ::= <any unicode codepoint except '"' or '\'>
escape_seq  ::= "\\" ("\\" | "\"" | "'" | "n" | "r" | "t" | "0")
              | "\\x" hex_digit hex_digit
              | "\\u" "{" hex_digit ("_"? hex_digit){0,5} "}"
              | "\\" line_terminator whitespace*
```

普通字符串用双引号（`"`）括起。

```nabi
"hello"
"hello, 세계"
""
"a string
spanning
several lines"
```

它可以包含任何 Unicode 码位，也可以原样包含换行。始终没有闭合的字符串是编译错误：闭合的 `"` 必须位于同一文件中，所以直到文件末尾都没有闭合的字符串是错误。

### 转义序列

识别以下转义序列。

| 序列       | 含义                                                                 |
|------------|----------------------------------------------------------------------|
| `\\`       | 反斜杠（`U+005C`）                                                   |
| `\"`       | 双引号（`U+0022`）                                                   |
| `\'`       | 单引号（`U+0027`）                                                   |
| `\n`       | 换行（`U+000A`）                                                     |
| `\r`       | 回车（`U+000D`）                                                     |
| `\t`       | 制表符（`U+0009`）                                                   |
| `\0`       | NULL（`U+0000`）                                                     |
| `\xHH`     | 一个字节（两位十六进制数字；只限 ASCII 范围 `U+0000`-`U+007F`）      |
| `\u{H...}` | 任意 Unicode 标量值（1-6 位十六进制数字，最大 `U+10FFFF`，不能是代理码位 `U+D800`-`U+DFFF`） |

`\u{...}` 中的十六进制数字可以用 `_` 分隔（例如 `\u{1_F600}`）。上面所列以外的任何反斜杠序列都是词法错误；未知的转义绝不会被静默地保留为原来的字符。错误指向转义本身，并说明应当怎样写：代理码位（`\u{D800}`，UTF-16 代理对的一半）会给出该字符自身的码位，字符串中 `\x80` 及以上的值会指向 `\u{80}`，不需要转义的字符之前的反斜杠（`\%`）会提示去掉它。

### 行接续

当字符串中的反斜杠紧挨在行终止符之前时，反斜杠、行终止符以及下一行的前导空白全部被省略。

```nabi
"a long string that \
 reads as one line"
// resulting contents: "a long string that reads as one line"
```

这一规则让长字符串可以在源代码中拆成多行，而不在结果值中插入换行。

## 1.7.2. 原始字符串

原始字符串以 `r` 前缀后跟双引号书写。

```nabi
r"raw\n"
r"C:\path\to\file"
```

原始字符串内部不处理任何转义，所以 `\n` 保留为两个字符。如果原始字符串的内容需要包含闭合的 `"`，可以在两侧用相同数量的 `#` 包围来更改定界符。

```nabi
r#"a string may contain "double quotes""#
r##"even r#"this form"# works"##
```

开头的 `r##"` 必须以 `#` 数量完全相同的闭合 `"##` 结束；起作用的是开头一侧 `#` 的数量。原始字符串不支持行接续（`\` + 行终止符），因为按定义，原始字符串原样保留每一个字符。

## 1.7.3. 格式字符串

格式字符串有两种形式：`f"..."` 和 `f"""..."""`（与 Python 3.12 / PEP 701 规则相同）。

```nabi
f"x = {x}"
f"sum = {a + b}, diff = {a - b}"
f"""
  name: "{name}"
  total: {items
      .len()}
"""
```

- 文本中的 `{{` 和 `}}` 是单个花括号。
- `f"""..."""` 的文本可以原样包含 `"`，插值孔中的代码可以跨越多行。`f"..."` 中的插值孔只能在一行之内。没有不带 `f` 的 `"""` 字符串。

f-string 是 `str`。在类型为 `fmt::Arguments` 的槽中，它则是 `Arguments`：插值孔在那里求值，而文本只在该值被格式化时才逐段生成（[stdlib 2.10.15](../../refs-standard-libraries/200-core/210-fmt.md#21015-arguments-an-f-string-formatted-later)）。

### 插值孔

插值孔 `{ .. }` 的内部由普通词法分析器读取的普通词法单元组成。

- 可以重复使用外层的引号（`f"{s.split(" ")}"`、`f"{d["k"]}"`）。f-string 可以嵌套任意深度。
- 插值孔内的字符串字面量保留自己的转义（`f"{"a\tb"}"`）。
- 字符串字面量之外的 `\` 是错误。诊断会建议原样写出 `"`。
- 表达式在括号深度为 0 的 `}` 或 `:` 处结束。`::` 是路径分隔符。
- `{expr=}`：深度为 0 的 `=` 之后（跳过空格）跟 `}` 或 `:` 时，结束表达式并回显它。该插值孔先写出自身直到 `=` 及空格为止的源文本，然后写出值的 `Debug` 形式，或者在后跟格式说明时按该格式写出值（`f"{x=}"` 为 `x=5`，`f"{x = :.2f}"` 为 `x = 5.00`）。

```nabi
f"name = {user.name ?? "anon"}"     // OK
f"name = {user.name ?? \"anon\"}"   // ERROR: \ inside a hole
f"{\"ab\".replace("a", "b")}"  // ERROR: write f"{"ab".replace("a", "b")}"
```

### 格式说明符

表达式之后可以在冒号（`:`）后跟一个格式说明符。

```nabi
f"{x:.2f}"        // two decimal places
f"{n:0>5d}"       // 5 digits, zero-filled, right-aligned
f"{val:?}"        // debug format
```

格式说明符的语法如下。

```
spec  := [fill][align][sign]['#'][0][width][grouping]['.'precision][type]
grouping := ',' | '_'
align := '<' | '>' | '^' | '='
sign  := '+' | '-' | ' '
type  := 'd' | 'g' | 's' | 'f' | 'b' | 'o' | 'x' | 'X' | 'e' | 'E' | '?' | '%'
```

如果有 `width` 而没有 `align`，数字（整数和浮点数）右对齐，其他类型左对齐。给出 `<` `>` `^`（可带填充字符）时，任何类型都按该对齐方式。f-string 在插值孔类型已知的阶段被转换为格式化代码，所以对齐默认值和格式说明检查由类型决定。各插值孔依次写入单个 `Formatter` 的缓冲区，不为每个插值孔创建中间字符串（[stdlib 2.10.1](../../refs-standard-libraries/200-core/210-fmt.md#2101-dispatch)）。

| 部分         | 含义                                                                                         |
|--------------|----------------------------------------------------------------------------------------------|
| `fill`       | 填充字符（默认为空格）。其后必须紧跟 `align`                                                 |
| `align`      | `<` 左对齐，`>` 右对齐，`^` 居中，`=` 在符号与数字之间填充（仅限数字）                       |
| `sign`       | `+` 对正数也显示 `+`，空格对正数显示一个空格，`-` 为默认值（只对负数显示 `-`）               |
| `#`          | 对 `b` / `o` / `x` / `X` 加 `0b` / `0o` / `0x` 前缀；`g` 保留末尾的零；`?` 美化输出（`{x:#?}`） |
| `0`          | 用零填充数字（与填充字符为 `0` 的 `=` 对齐相同）                                             |
| `grouping`   | 仅限数字：`,` 在每 3 位整数数字之间（仅十进制形式），`_` 在每 3 位之间（`b` `o` `x` `X` 为 4 位） |
| `.precision` | 对浮点数是小数点后的位数（不带转换）；对字符串等是最大长度（截断）；对整数忽略               |

| `type`          | 适用于                  | 含义                                                              |
|-----------------|-------------------------|-------------------------------------------------------------------|
| （无）, `d`, `s` | 所有类型               | `Display`                                                         |
| `g`             | 数字                    | 通用格式（`precision` 位有效数字）                                |
| `f`             | 数字                    | 定点（`precision` 位）                                            |
| `b` `o` `x` `X` | 整数                    | 2 / 8 / 16 进制，按整数类型的宽度（`{-1i8:x}` 为 `ff`）           |
| `e` `E`         | 整数、浮点数            | 指数记法                                                          |
| `?`             | 所有类型                | `Debug`。可以与宽度 / 对齐组合                                    |
| `%`             | 数字                    | 乘以 100 后按 `f` 形式（默认 6 位），再加 `%`                     |

`g` 是 C 和 Python 的通用格式：`precision` 位有效数字（省略时为 6，为 0 时为 1），当指数小于 -4 或不小于精度时采用指数形式，否则采用定点形式；除非有 `#`，否则去掉末尾的零和单独的 `.`。指数带符号且至少两位：`{1234.5678:.3g}` 为 `1.23e+03`，`{1e20:g}` 为 `1e+20`，`{0.0001:g}` 为 `0.0001`，`{1234567:g}` 为 `1.23457e+06`。

静态的格式说明在编译期对照插值孔的类型进行检查；不匹配时是指向该插值孔的错误（`s: str` 时的 `{s:x}` 等）。实现了 `Display` 的自定义类型接受所有类型字母、符号和分组，并把它们交给自己的 `Display::fmt`，后者再传给它写出的数字（某个量的 `{q:.2e}` 为 `1.50e3 m`）。每个类型字母调用的 trait 由标准库格式化规范定义（[stdlib 2.10](../../refs-standard-libraries/200-core/210-fmt.md)）。

### 动态格式说明符

格式说明符内部可以嵌入表达式。`{expr}`（Python 风格）和 `${expr}` 都被接受。

```nabi
f"{x:.{prec}f}"           // dynamic precision
f"{x:>${width}.${prec}f}" // dynamic width + precision
f"{val:{full_spec}}"      // entire specifier dynamic
```

- 嵌入的表达式被求值、转换为字符串，并成为说明符文本的一部分。展开后的结果必须满足 `spec` 语法和插值孔的类型；否则会在运行时 panic。
- 嵌套的插值孔没有自己的说明符。
- 说明符中的 `$$` 是单个 `$`。不构成 `${` 的单独 `$` 原样保留。

### 词法处理

词法分析器把格式字符串切分为以下词法单元。

```
FStrStart                     f" or f"""
  FStrText    "x = "          ({{ / }} folded into braces)
  HoleStart
    (ordinary tokens: expression)
    HoleSpec                  (optional) :
      SpecText / nested hole
  HoleEnd
  FStrText    ", y = "
FStrEnd
```

插值孔内部的表达式由普通的表达式解析器处理。

## 1.7.4. 相邻字符串的自动连接

Nabi 不采用 C 和 Python 风格的相邻字符串自动连接（`"abc" "def"` → `"abcdef"`）。连接需要显式的运算符或方法。

## 1.7.5. 字节串

```
byte_string_lit  ::= 'b"' byte_string_item* '"'
byte_string_item ::= <any ASCII byte except '"' or '\'> | byte_escape
```

字节串是 `b` 前缀后跟双引号。它求值为容纳其字节的定长数组 `[u8; N]`，其中 `N` 是字节数。

```nabi
let magic = b"\x7FELF";          // [u8; 4]
let req: Slice<u8> = b"GET /\r\n";
```

直接写出的字符必须是 ASCII；其他任何字节都以转义写出。转义序列与 `c'A'`（[1.8.1](108-character-literals.md#181-three-kinds)）一样遵循 1.7.1 的表：`\xHH` 可以是 `\x00`-`\xFF` 中的任何值，每个转义的值都必须位于 `U+0000`-`U+00FF` 之内。直接写出的非 ASCII 字符或大于 `U+00FF` 的转义是词法错误。行接续（1.7.1）不适用：行终止符之前的 `\` 是未知转义，属于词法错误。

当期望类型是 `Slice<u8>`，或者是含有 `Slice<u8>` 成员且没有数组成员的和类型时，该字面量改为该数组的 `Slice<u8>` 视图，如同写作 `b"..."[:]`。
