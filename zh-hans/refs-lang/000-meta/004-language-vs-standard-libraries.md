# 0.4. 语言与标准库的边界

本文档声明语言所定义的内容与标准库所定义的内容之间的边界。这一边界是 Nabi 规范的核心决定，后续所有规范文档都以它为前提编写。

## 0.4.1. 语言定义的内容

语言规范直接涵盖的范围分为以下五类。

### 1. 逻辑流

第一类是传递值的语法及其含义。它包括分支、循环、模式匹配、异常处理和带标签的跳转；async 和生成器的语法，即它们的声明符和运算符关键字，也属于这一类。

### 2. 容器语法

第二类是定义用户类型的形式。积类型（记录）把多个字段组合成一个；和类型（带标签）持有多个变体之一。不带标签的 `union` 是把同一块内存解释为多种类型的手段；trait 是声明一组行为的手段；`impl` 块是放置 trait 和方法具体实现的地方。最后，泛型使接受类型作为参数的形式成为可能。

### 3. 元系统

第三类是属性系统，它附着在前两类之上并绑定行为。它由标准属性（语言识别的一组固定名称）以及用于用户定义属性和派生的模板系统组成。

### 4. 变量 / 可见性 / 模块

第四类是关于名称和暴露的约定。它包括变量声明关键字、引用修饰符、全局和常量关键字，以及可见性级别和模块与包层面的名称暴露约定。

### 5. 运算符语法

最后一类是 `a + b`、`s[1:3]`、`x.f` 和 `f(args)` 等记法的形状。

然而，语言并不定义这些记法表示什么行为。一个记法通过脱糖为标准库中注册的 trait 方法来获得含义。

## 0.4.2. 标准库定义的内容

上述五类之外几乎所有的含义都由标准库负责。具体来说：数值和字符类型及其运算；算术、比较、逻辑、位运算、索引和区间等运算符语义，它们全部在标准库中定义为 trait `impl`；包含类型间所有转换规则的转换矩阵；以及以列表、映射、集合、元组和字符串为代表的集合类型。此外，迭代器、流和 future 等抽象；以原子、互斥锁和通道为代表的并发原语；任务、线程和并行执行 API；I/O、时间、随机数和网络；以及所有错误类型，都由标准库定义。

语言不知道这些库元素的名称。编译器只通过元系统的属性绑定来识别特定的库类型，而这些绑定本身也写在标准库中。

## 0.4.3. 边界的结果

### 语法归语言，行为归库

这一划分的第一个结果是记法与含义之间的分工。

> [!IMPORTANT]
> 语言定义所有记法，但作用于值的运算的含义
> 由标准库中注册的 trait 方法决定。

| 记法        | 语言决定的内容             | 库决定的内容                                      |
|-------------|----------------------------|---------------------------------------------------|
| `a + b`     | 词法单元序列、优先级       | `+` 是哪个 trait 方法、结果类型                   |
| `s[1:3]`    | 切片记法的形状             | 索引、边界检查、结果类型                          |
| `x.f()`     | 方法调用的形状             | 方法分派规则                                      |
| `let x = 1` | 声明的形状                 | 字面量 `1` 的类型                                 |

### 语言层面问题的范围

这一划分的第二个结果是对问题进行分类的标准。面对任何设计或实现决定时，首先要判断它是语言层面的问题还是库层面的问题。

留在语言层面的问题限于以下几个领域。第一，编译器语义：名称解析、闭包捕获、可见性和错误诊断。第二，语法决定：转义、优先级、字面量后缀、切片记法的形状等。第三，运行时调用约定和内存模型，包括对象布局和调用约定。第四，资源管理：生命周期和异常传播机制。第五，类型系统规则：trait 不能作类型、渐进类型、niche 优化等。

### 交给库层面的内容

上述列表之外，几乎所有作用于值的运算都由库决定。因此，本规范不直接规定这类运算的语义。

规范转而说明以下内容：该运算脱糖为哪个 trait 方法调用；定义该 trait 的库层级的位置约定；以及未定义时出现的编译错误的形式。

这一划分就是 Nabi 的设计原则“核心要窄，库要丰富”在规范层面的实现方式。

## 0.4.4. 实现限制

语言对嵌套、链长度、值大小或编译期求值不设固定限制。实现可以设定自己的限制；这些限制由实现定义，不是语言要求。Nabi 的限制如下：

| 限制 | Nabi |
|-------|-----|
| 解析器嵌套深度 | 256 |
| 运算符 / 后缀链的环节数（[3.2.6a](../003-expressions/302-precedence-and-associativity.md#326a-实现限制)） | 4096 |
| 值类型大小（[2.6.3](../002-types/206-sum-types.md)） | 65536 个展平后的标量槽或 4 GiB |
| `const` 求值（[5.2.4](../005-modules/502-const.md)） | 4,000,000 步，调用深度 128 |

超出任何一项都是编译错误。
