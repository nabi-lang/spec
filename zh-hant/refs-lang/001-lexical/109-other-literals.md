# 1.9. 布林值與哨兵值字面值

Nabi 有三個採取關鍵字形式、但實際上表示值的字面值。在文法上，它們定義如下。

```
sentinel_lit    ::= "true" | "false" | "none"
```

## 1.9.1. 布林值字面值

布林值字面值寫法如下。

```nabi
true
false
```

布林值字面值恰好由 `true` 與 `false` 兩個語彙單元組成。這兩個名稱都在[關鍵字](105-keywords.md)的保留清單中，不能再用作識別字。它們求值為標準函式庫的布林型別（`bool`）；其確切定義由型別系統涵蓋。

## 1.9.2. 哨兵值字面值：`none`

哨兵值字面值寫法如下。

```nabi
none
```

`none` 是表示沒有值的唯一字面值。它占據其他語言中 `null`、`nil`、`None` 與 `undefined` 的位置，並被保留為關鍵字，因此不能用作識別字。它填入哪個和型別的空槽位由上下文決定；其語意定義於型別系統規格。

## 1.9.3. 語彙分類

這三個字面值屬於[語彙結構](102-lexical-structure.md)中的布林值 / 哨兵值字面值類別。它們之所以與關鍵字語彙單元類別分開歸類，是因為它們是出現在值位置的語彙單元，剖析器在可以出現字面值之處接受它們。

在語彙階段只保證下列事項：`true`、`false` 與 `none` 一律被區分為相同的語彙單元類別，絕不會被重新解讀為識別字或其他關鍵字。

## 1.9.4. 不採用的字面值

其他語言中常見的下列字面值，在語彙階段不作為另外的語彙單元引入。浮點數的無限大與 NaN 以標準函式庫常數提供，而其他形式的「空」，即 `undefined`、`null` 與 `nil`，全都統一為 `none`。**unit** 值（`()`）不在語彙階段出現，而是在運算式階段以空元組記法出現。

字面值種類越少，學習成本越低，工具需要處理的範圍也越小。
