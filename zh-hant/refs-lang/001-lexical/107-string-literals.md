# 1.7. 字串字面值

字串字面值是表示字元序列的語彙單元。本文件只涵蓋語彙形式；結果求值為哪個函式庫型別，由標準函式庫的字面值處理器決定。位元組字串（1.7.5）是例外：它的型別由語言固定。

## 1.7.1. 一般字串

```
string_lit  ::= '"' string_item* '"'
string_item ::= string_char | escape_seq
string_char ::= <any unicode codepoint except '"' or '\'>
escape_seq  ::= "\\" ("\\" | "\"" | "'" | "n" | "r" | "t" | "0")
              | "\\x" hex_digit hex_digit
              | "\\u" "{" hex_digit ("_"? hex_digit){0,5} "}"
              | "\\" line_terminator whitespace*
```

一般字串以雙引號（`"`）括起來。

```nabi
"hello"
"hello, 세계"
""
"a string
spanning
several lines"
```

它可以包含任何 Unicode 碼位，包括原樣的換行。從未關閉的字串是編譯錯誤：結尾的 `"` 必須在同一個檔案中，因此直到檔案結尾都未關閉的字串是錯誤。

### 跳脫序列

辨識的跳脫序列如下。

| 序列       | 意義                                                                 |
|------------|----------------------------------------------------------------------|
| `\\`       | 反斜線（`U+005C`）                                                   |
| `\"`       | 雙引號（`U+0022`）                                                   |
| `\'`       | 單引號（`U+0027`）                                                   |
| `\n`       | 換行（`U+000A`）                                                     |
| `\r`       | 歸位（`U+000D`）                                                     |
| `\t`       | 水平定位（`U+0009`）                                                 |
| `\0`       | NULL（`U+0000`）                                                     |
| `\xHH`     | 一個位元組（兩位十六進位數字；僅限 ASCII 範圍 `U+0000`-`U+007F`）    |
| `\u{H...}` | 任意 Unicode 純量值（1-6 位十六進位數字，最大 `U+10FFFF`，不得是代理碼位 `U+D800`-`U+DFFF`） |

`\u{...}` 內的十六進位數字可以用 `_` 分隔（例如 `\u{1_F600}`）。上列以外的任何反斜線序列都是語彙錯誤；未知的跳脫序列絕不會被默默保留為原本的字元。錯誤指向跳脫序列本身並說明應該寫什麼：代理碼位（`\u{D800}`，UTF-16 碼位對的一半）會改為指出該字元本身的碼位，字串中 `\x80` 以上會指向 `\u{80}`，而在不需要跳脫的字元之前的反斜線（`\%`）會提示把它拿掉。

### 行接續

當字串中的反斜線緊接在行終止符之前時，反斜線、行終止符以及下一行開頭的空白都會被省略。

```nabi
"a long string that \
 reads as one line"
// resulting contents: "a long string that reads as one line"
```

這條規則讓長字串可以在原始碼中分成多行，而不會在結果值中插入換行。

## 1.7.2. 原始字串

原始字串以 `r` 前綴後接雙引號撰寫。

```nabi
r"raw\n"
r"C:\path\to\file"
```

原始字串內不處理任何跳脫序列，因此 `\n` 保留為兩個字元。若原始字串的內容需要結尾的 `"`，可以在兩側加上相同數量的 `#` 來改變分隔符。

```nabi
r#"a string may contain "double quotes""#
r##"even r#"this form"# works"##
```

開頭的 `r##"` 必須以 `#` 數量完全相同的結尾 `"##` 結束；起作用的是開頭一側的 `#` 數量。原始字串不支援行接續（`\` + 行終止符），因為依定義，原始字串原樣保留每一個字元。

## 1.7.3. 格式字串

格式字串有兩種形式：`f"..."` 與 `f"""..."""`（與 Python 3.12 / PEP 701 的規則相同）。

```nabi
f"x = {x}"
f"sum = {a + b}, diff = {a - b}"
f"""
  name: "{name}"
  total: {items
      .len()}
"""
```

- 文字中的 `{{` 與 `}}` 是單一個大括號。
- `f"""..."""` 的文字可以原樣包含 `"`，洞中的程式碼可以跨越多行。`f"..."` 中的洞只能是單行。沒有不帶 `f` 的 `"""` 字串。

f-string 是 `str`。在型別為 `fmt::Arguments` 的槽位中，它改為 `Arguments`：洞在那裡求值，而文字只在值被格式化時才逐段產生（[stdlib 2.10.15](../../refs-standard-libraries/200-core/210-fmt.md#21015-arguments稍後才格式化的-f-string)）。

### 洞

洞 `{ .. }` 的內部由一般語彙分析器讀取的一般語彙單元組成。

- 可以重複使用外層的引號（`f"{s.split(" ")}"`、`f"{d["k"]}"`）。f-string 可以巢狀到任意深度。
- 洞內的字串字面值保有自己的跳脫序列（`f"{"a\tb"}"`）。
- 字串字面值之外的 `\` 是錯誤。診斷會建議原樣寫出 `"`。
- 運算式在括號深度 0 的 `}` 或 `:` 處結束。`::` 是路徑分隔符。
- `{expr=}`：深度 0 的 `=` 之後（略過空格）接著 `}` 或 `:` 時，結束運算式並回顯它。洞會寫出它自己到 `=` 為止的原始碼文字與空格，再寫出值的 `Debug` 形式；若後面接著規範，則寫出依該規範格式化的值（`f"{x=}"` 是 `x=5`，`f"{x = :.2f}"` 是 `x = 5.00`）。

```nabi
f"name = {user.name ?? "anon"}"     // OK
f"name = {user.name ?? \"anon\"}"   // ERROR: \ inside a hole
f"{\"ab\".replace("a", "b")}"  // ERROR: write f"{"ab".replace("a", "b")}"
```

### 格式規範

運算式之後可以接一個冒號（`:`）與格式規範。

```nabi
f"{x:.2f}"        // two decimal places
f"{n:0>5d}"       // 5 digits, zero-filled, right-aligned
f"{val:?}"        // debug format
```

格式規範的文法如下。

```
spec  := [fill][align][sign]['#'][0][width][grouping]['.'precision][type]
grouping := ',' | '_'
align := '<' | '>' | '^' | '='
sign  := '+' | '-' | ' '
type  := 'd' | 'g' | 's' | 'f' | 'b' | 'o' | 'x' | 'X' | 'e' | 'E' | '?' | '%'
```

若有 `width` 而沒有 `align`，數字（整數與浮點數）靠右對齊，其他型別靠左對齊。給出 `<` `>` `^`（可帶填充字元）時，任何型別都遵循該對齊方式。f-string 在洞的型別已知的階段被轉成格式化程式碼，因此對齊的預設值與規範檢查由型別決定。洞依序寫入單一 `Formatter` 的緩衝區，不會為每個洞建立中間字串（[stdlib 2.10.1](../../refs-standard-libraries/200-core/210-fmt.md#2101-分派)）。

| 部分         | 意義                                                                                         |
|--------------|----------------------------------------------------------------------------------------------|
| `fill`       | 填充字元（預設為空格）。後面必須緊接 `align`                                                 |
| `align`      | `<` 靠左、`>` 靠右、`^` 置中、`=` 在正負號與數字之間填充（僅限數字）                         |
| `sign`       | `+` 讓正數也顯示 `+`，空格讓正數顯示一個空格，`-` 是預設值（只有負數顯示 `-`）               |
| `#`          | 對 `b` / `o` / `x` / `X` 加上 `0b` / `0o` / `0x` 前綴；`g` 保留尾隨的零；`?` 以美化格式印出（`{x:#?}`） |
| `0`          | 以零填充數字（等同於填充字元為 `0` 的 `=` 對齊）                                             |
| `grouping`   | 僅限數字：`,` 每 3 位整數數字分組（僅限十進位形式），`_` 每 3 位分組（`b` `o` `x` `X` 為每 4 位） |
| `.precision` | 浮點數的小數點後位數（無型別字母時）；字串等的最大長度（截斷）；整數忽略                     |

| `type`          | 適用於                  | 意義                                                              |
|-----------------|-------------------------|-------------------------------------------------------------------|
| （無）、`d`、`s` | 所有型別               | `Display`                                                         |
| `g`             | 數字                    | 一般格式（`precision` 位有效數字）                                |
| `f`             | 數字                    | 定點表示（`precision` 位）                                        |
| `b` `o` `x` `X` | 整數                    | 2 / 8 / 16 進位，以整數型別的寬度表示（`{-1i8:x}` 是 `ff`）       |
| `e` `E`         | 整數、浮點數            | 指數表示                                                          |
| `?`             | 所有型別                | `Debug`。可以與寬度 / 對齊並用                                    |
| `%`             | 數字                    | 乘以 100 後以 `f` 形式表示（預設 6 位），再加上 `%`               |

`g` 是 C 與 Python 的一般格式：`precision` 位有效數字（未指定時為 6，為 0 時視為 1），指數小於 -4 或不小於精度時用指數形式，否則用定點形式；除非有 `#`，否則尾隨的零與單獨的 `.` 會被去掉。指數帶有正負號且至少兩位數：`{1234.5678:.3g}` 是 `1.23e+03`，`{1e20:g}` 是 `1e+20`，`{0.0001:g}` 是 `0.0001`，`{1234567:g}` 是 `1.23457e+06`。

靜態的規範會在編譯期對照洞的型別檢查；不符時是指向該洞的錯誤（`s: str` 時的 `{s:x}` 等）。自訂型別若有 `Display`，會接受每一個型別字母、正負號與分組，並把它們交給它的 `Display::fmt`，再由它傳給它所寫出的數字（某個量的 `{q:.2e}` 是 `1.50e3 m`）。各型別字母所呼叫的 trait 由標準函式庫的格式化規格定義（[stdlib 2.10](../../refs-standard-libraries/200-core/210-fmt.md)）。

### 動態格式規範

格式規範內可以嵌入運算式。`{expr}`（Python 風格）與 `${expr}` 都被接受。

```nabi
f"{x:.{prec}f}"           // dynamic precision
f"{x:>${width}.${prec}f}" // dynamic width + precision
f"{val:{full_spec}}"      // entire specifier dynamic
```

- 嵌入的運算式會被求值、轉成字串，並成為規範文字的一部分。展開後的結果必須滿足 `spec` 文法與洞的型別；否則會在執行時 panic。
- 巢狀的洞沒有自己的規範。
- 規範內的 `$$` 是單一個 `$`。不構成 `${` 的單獨 `$` 原樣保留。

### 語彙處理

語彙分析器把格式字串切分為下列語彙單元。

```
FStrStart                     f" or f"""
  FStrText    "x = "          ({{ / }} folded into braces)
  HoleStart
    (ordinary tokens: expression)
    HoleSpec                  (optional) :
      SpecText / nested hole
  HoleEnd
  FStrText    ", y = "
FStrEnd
```

洞內的運算式由一般的運算式剖析器處理。

## 1.7.4. 相鄰字串的自動串接

不採用 C 與 Python 式的相鄰字串自動串接（`"abc" "def"` → `"abcdef"`）。串接需要明確的運算子或方法。

## 1.7.5. 位元組字串

```
byte_string_lit  ::= 'b"' byte_string_item* '"'
byte_string_item ::= <any ASCII byte except '"' or '\'> | byte_escape
```

位元組字串是 `b` 前綴後接雙引號。它求值為存放其位元組的固定長度陣列 `[u8; N]`，其中 `N` 是位元組的數量。

```nabi
let magic = b"\x7FELF";          // [u8; 4]
let req: Slice<u8> = b"GET /\r\n";
```

直接寫出的字元必須是 ASCII；其他任何位元組都以跳脫序列撰寫。跳脫序列和 `c'A'`（[1.8.1](108-character-literals.md#181-三種類別)）一樣遵循 1.7.1 的表格：`\xHH` 可以是 `\x00`-`\xFF` 的任何值，而每個跳脫序列的值都必須位於 `U+0000`-`U+00FF` 之內。直接寫出的非 ASCII 字元，或大於 `U+00FF` 的跳脫序列，是語彙錯誤。行接續（1.7.1）不適用：行終止符之前的 `\` 是未知的跳脫序列，也是語彙錯誤。

當預期型別是 `Slice<u8>`，或是含有 `Slice<u8>` 成員且沒有陣列成員的和型別時，字面值改為該陣列的 `Slice<u8>` 檢視，就像寫成 `b"..."[:]` 一樣。
