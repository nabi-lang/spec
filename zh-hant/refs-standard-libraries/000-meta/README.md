## 本章的角色

本章不直接定義個別的 trait 或型別，而是彙整函式庫**整體**必須一致遵循的規則與
政策。

**三層模型**規定相依的方向：`std` 可以使用 `core` 與 `bare`，
`core` 可以使用 `bare`，但不允許反方向的相依。**匯入政策**
規定每個使用者檔案都會隱含匯入的 prelude `core::prelude`，並列出其中的名稱。接著的**內建函式**條目說明
標準函式庫方法如何連接到編譯器後端（PrimOp 等），最後的 **lang
槽位**條目說明編譯器透過 `#[lang(...)]` 屬性查找的 100 個槽位如何對應到
標準函式庫的項目。

這些政策定義好之後，[200-core/](../200-core/) 的 trait 定義才能接續。
